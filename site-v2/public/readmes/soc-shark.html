⚡ Install in one line

Downloads the ready-to-run binary for your system from the latest release, checks its SHA-256, puts socshark on your PATH and tests it with a demo capture. No compiler needed: it takes seconds. Run it again any time to update.

Windows · PowerShell

irm https://raw.githubusercontent.com/Ruby570bocadito/soc-shark/main/install.ps1 | iex

Linux / macOS · bash

curl -fsSL https://raw.githubusercontent.com/Ruby570bocadito/soc-shark/main/install.sh | bash

Then open the app:

socshark gui
What each installer does, live capture permissions and options
  • Windows (install.ps1): installs socshark.exe into %USERPROFILE%\.socshark\bin and adds it to your user PATH. For live capture install Npcap (already there if you have Wireshark) with WinPcap API-compatible Mode ticked.
  • Linux (install.sh): installs into ~/.local/bin, adds libpcap if it is missing and grants the binary the capture capabilities (setcap cap_net_raw,cap_net_admin=ep), so live capture works without sudo. Be aware that, unlike Wireshark (where only the small dumpcap helper holds them), these capabilities apply to the whole socshark binary, parsers and GUI included; a separate privileged capture helper is planned (see docs/security.md). If you prefer not to, use SOCSHARK_NO_SETCAP=1 and capture with sudo or open .pcap files. The binary runs on any distribution with glibc 2.17 or newer (x86_64 and ARM64).
  • macOS: same script, one universal binary (Apple Silicon and Intel); live capture needs sudo (or Wireshark's ChmodBPF).
  • No binary for your system, or it fails to start? The installer builds from source instead, installing what that needs (Git, Rust, a C linker; on Windows, the Visual Studio C++ Build Tools).
  • Options (environment variables): SOCSHARK_VERSION (e.g. 0.9.2; default: the latest), SOCSHARK_FROM_SOURCE=1 (build instead of downloading), SOCSHARK_BIN (Linux/macOS install folder), SOCSHARK_NO_SETCAP=1.

Prefer to download it yourself? Every release has socshark for Windows (.zip), Linux x86_64 and ARM64, and macOS (.tar.gz), plus SHA256SUMS to check them: unpack it and run socshark gui.

Why SOC SHARK

Wireshark answers "what is inside this packet?". SOC SHARK answers "what is happening on my network, and what should I worry about?" Conversations instead of packets, meaning instead of hex, alerts instead of endless scrolling:

  • every conversation is one sentence — "The computer «DESKTOP-AB12» used Telnet with the router" — with a ✓ / ! / ✕ status;
  • alerts are grouped into stories with what to do and the MITRE ATT&CK technique;
  • and when you need the detail, it is all there, Wireshark-style: every packet, its layers explained field by field, and its bytes.

Usage

# Graphical interface: live network, or open / drag a capture (pcap or pcapng)
socshark gui
socshark gui -r capture.pcapng

# Terminal interface
socshark tui -r capture.pcap

# Plain-language report in English (one HTML file to save, print or send)
socshark report -r capture.pcap --lang en

# Summary table, JSONL and the filter language (docs/filter-dsl.md)
socshark capture -r capture.pcap
socshark capture -r capture.pcap --json - | jq '.risk_score'
socshark capture -r capture.pcap -f "tcp.port == 443 || flow.risk >= 50"

# Carve HTTP files and detect disguised ones (T1036); offline threat intel
socshark capture -r capture.pcap --carve-files
socshark capture -r capture.pcap --intel-feodo feodo.txt --intel-tor tor-exits.txt

# Follow a reassembled TCP stream
socshark follow -r capture.pcap --flow "93.184.216.34:443"

# Export to a SIEM
socshark export -r capture.pcap -F ecs -o ecs.jsonl
socshark export -r capture.pcap -F wazuh -o wazuh.jsonl

# Live capture from the command line (BPF pushed down to the kernel)
socshark daemon --list
socshark daemon -i eth0 --bpf "tcp port 443" --json flows.jsonl

# No capture at hand? Generate one: an attack demo, or a home network
socshark dev sample-pcap -o demo.pcap
socshark dev sample-pcap --escenario casa -o home.pcap

Build from source

Requirements: Rust 1.88+ and a C linker. Live capture also needs libpcap (Linux; built into macOS) or Npcap (Windows) at run time — it is loaded on the fly, nothing to link at build time.

git clone https://github.com/Ruby570bocadito/soc-shark.git
cd soc-shark
./install.sh                     # builds this copy and installs it; or: cargo build --release
./target/release/socshark gui -r examples/demo.pcap

Live capture on Linux without the installer: grant the permission once with sudo setcap cap_net_raw,cap_net_admin=ep "$(command -v socshark)", or run it with sudo.

Responsible use

SOC SHARK is a defensive tool for SOC and Blue Team analysts, researchers and anyone who wants to understand their own network. Capturing traffic on networks you do not manage may be illegal where you live: use it only on your own networks or with explicit permission and, at work, according to your monitoring policy.
